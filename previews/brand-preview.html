2. Wordmark colour options

"resale" is the name people say; ".com.pk" tells them where to find it. The options differ in how much each half stands out. Each card shows light and dark backgrounds at header size.

Why A is recommended

OptionContrast on whiteVerdict
A · Teal "resale" + slate ".com.pk"9.5 : 1 / 4.8 : 1 (AA)Teal ties the name to the mark and the primary button colour. Muted domain keeps "resale" as the thing people remember. Orange stays reserved for the mark and commercial accents (guidelines §3 colour hierarchy).
B · All ink17.9 : 1Safest and most neutral; matches header text colour. Loses brand colour, so the name feels generic next to a colourful mark.
C · Ink "resale" + teal ".com.pk"17.9 : 1 / 5.1 : 1Puts the colour on the least important part. Reads like a link.
D · All teal9.5 : 1Strong and simple, but ".com.pk" gets the same weight as the name and the lockup feels heavy at small sizes.
E · Orange dot accentDot ≈3 : 1 (fails as text)Eye-catching, but adds a new brand device the guidelines don't define, and the dot vanishes on small screens. Use for campaigns only, if at all.
F · Stacked (current site)n/aCompact, but ".com.pk" becomes tiny (≈11px) and hard to read; guidelines specify a single line.

The live site currently uses Hanken Grotesk 800 in a stacked lockup. The guidelines say Inter 600/700 and advise against 800/900. Option G shows the current font for comparison.
